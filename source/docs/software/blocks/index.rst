Programming with Blocks
=======================

Build a drivetrain program with Blocks. Start with four CIM motors and SPARK MAX controllers, then connect a gamepad for split-stick arcade drive. The tutorial walks through creating the program, deploying it, and checking the robot's response.

.. note::

   This tutorial is a draft awaiting checks with the current robot libraries and a physical robot test.
